AutoTranslate backend settings

The extension connects to one small backend. That backend can issue OpenAI Realtime credentials, run a fully local Whisper → Ollama → Piper pipeline, or support both.

For a remote backend, saving may trigger a browser permission prompt for that origin.

Provider behavior

OpenAI Realtime: captured tab audio is sent directly from the extension to OpenAI over WebRTC. The backend only creates a short-lived client secret.

Ollama local: captured tab audio is sent only to this backend. The backend converts and transcribes it with whisper.cpp, translates the text with your local Ollama model, and optionally generates a dub with Piper.

Privacy

Choose Ollama local when you want the audio, transcript, translation, and optional speech generation to remain on your machine. Ollama cloud models are not local; use a locally installed model and optionally set OLLAMA_NO_CLOUD=1 in Ollama for local-only operation.
